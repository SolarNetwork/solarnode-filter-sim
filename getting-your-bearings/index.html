    Getting your bearings¶

    When you first visit the application, you are presented with four main panes:

    • Setup (top left) - where you configure the overall parameters of the simulation, such as the datum to run through the filters, node metadata, and placeholders.
    • Control (middle left) - where you can start the simulation as well as import or export the filter settings as CSV files.
    • Filter Palette (bottom left) - a list of the available filters that you can drag onto the canvas.
    • Canvas (middle) - a flow chart style visualization of the simulation.
    • Inspector - shows the editable properties of a filter after you click on one in the canvas.

    Setup pane¶

    The Setup pane is where you configure the overall SolarNode simulation universe. At a minimum you must provide the initial datum to send into the filter execution flow. These initial datum represent data captured from SolarNode Datum Sources that read from devices like meters and power inverters.

    The History, Environment, Node Metadata, User Metadata, and Datum Metadata tabs in this pane allow you to configure other simulated SolarNode services like Metadata, Placeholders, Operational Modes, Local State, and more. Generally you need to configure everything your filters expect to be available when they run in SolarNode.

    Control pane¶

    The Control pane is where you can:

    • import filter settings from a SolarNode
    • export the simulation's filter settings, so you can apply them to a SolarNOde
    • add external filter settings, like those contributed by solarnode-config-* packages in SolarNodeOS; these are not exported with your simulation settings
    • run (or debug) the simulation

    The Entry Point is the name of the filter to pass the input datum to when you run the simulation. Typically this is the Main Filter Chain, but you can actually specify any filter in the simulation.

    Filter palette¶

    The Filter palette shows you all the available filters you can use in the simulator. Simply drag a filter from the palette over to the canvas to add it to the simulation. Drop the filter on any connector line between filters to insert that filter into the execution flow at that point.
