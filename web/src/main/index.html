The datum to run through the filters: a JSON object, or an array of objects, in the SolarNode datum format. A datum without a created date gets one, a minute after the datum before it.
Datum in the node's datum history when the run starts, which expression functions like latest() and offset() read. SolarNode keeps the latest 5 datum of each source.
Datum from before the filters were applied, which the unfiltered*() functions read.
The modes active when the run starts, separated by commas.
Local State CSV, as SolarNode exports it. Blank Created and Modified dates default to the first datum's date.
The node's metadata, which the Node Metadata Service provides: a JSON object with m, pm, and t properties. Expressions read it with functions like metadataAtPath('/pm/…').

User Metadata Services provide metadata from the SolarNetwork user account. Filters find one by its Service Name, like the Tariff filter's Metadata Service setting.
